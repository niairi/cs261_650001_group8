# Usability Feedback (US1–US5)

## 1. Objective
รวบรวมความคิดเห็นจากผู้ใช้ที่ทดลองใช้งานเว็บไซต์ Sprint 1 เพื่อประเมินความสะดวกในการใช้งาน ค้นหาปัญหา และจัดทำรายการปรับปรุง UI สำหรับ Task 54

## 2. Scope
การทดลองใช้งานครอบคลุม Use Cases และ User Stories ดังนี้

| Use Case | User Story | ฟังก์ชันที่ทดสอบ |
|---|---|---|
| UC1 | US1 | เข้าสู่ระบบด้วย TU Account |
| UC2 | US2, US3 | ดูสถานะห้องว่าง/ไม่ว่าง และจองห้อง |
| UC3 | US4 | ดูประวัติและยกเลิกการจอง |
| UC4 | US5 | รับอีเมลยืนยันการจองและแจ้งยกเลิก |

## 3. Feedback Collection
1. ให้ผู้ใช้ทดลองใช้งานเว็บไซต์ Sprint 1 ตาม User Stories US1–US5
2. สังเกตปัญหาและอุปสรรคที่เกิดขึ้นระหว่างการใช้งาน
3. รวบรวมความคิดเห็นและข้อเสนอแนะจากผู้ทดลองใช้
4. จัดกลุ่มปัญหาเป็นด้านตัวหนังสือ การจัดวาง และข้อมูลที่ขาด
5. จัดลำดับความสำคัญของปัญหาร่วมกับ Product Owner (PO)

## 4. Issues and Improvements

| ประเภทปัญหา | ปัญหาที่พบ | รายการปรับปรุง | Priority |
|---|---|---|---|
| ตัวหนังสือ | ขนาดฟอนต์เมนูด้านบนเล็กเกินไป | เพิ่มขนาดฟอนต์เมนู | รอจัดลำดับกับ PO |
| ข้อมูลที่ขาด | ไม่มีช่องแสดงเวลาปัจจุบัน | เพิ่มช่องแสดงเวลาปัจจุบัน | รอจัดลำดับกับ PO |
| การจัดวาง | องค์ประกอบบางส่วนจัดวางไม่เหมาะสม | ปรับตำแหน่งและระยะห่างขององค์ประกอบ | รอจัดลำดับกับ PO |

## 5. Expected Outcome

- ได้รวบรวมความคิดเห็นและข้อเสนอแนะจากผู้ทดลองใช้งานเว็บไซต์ Sprint 1
- ได้จัดกลุ่มปัญหาที่พบเป็นด้านตัวหนังสือ การจัดวาง และข้อมูลที่ขาด
- ได้จัดลำดับความสำคัญของปัญหาร่วมกับ Product Owner (PO)
- ได้รายการปรับปรุง UI ที่ชัดเจน เช่น การเพิ่มขนาดฟอนต์เมนูด้านบน และการเพิ่มช่องแสดงเวลาปัจจุบัน
- นำรายการปรับปรุงที่สรุปได้ไปใช้เป็นข้อกำหนดในการออกแบบหน้าเว็บใหม่ใน Task 54
