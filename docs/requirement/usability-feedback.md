# Usability Feedback (US1–US5)

## 1. Objective
รวบรวมความคิดเห็นจากผู้ใช้ที่ทดลองใช้งานเว็บไซต์ Sprint 1 เพื่อประเมินความสะดวกในการใช้งาน ค้นหาปัญหา และจัดทำรายการปรับปรุง UI สำหรับ Task 54

## 2. Scope

| Use Case | User Story | ฟังก์ชันที่ทดสอบ |
|---|---|---|
| UC1 | US1 | เข้าสู่ระบบด้วย TU Account |
| UC2 | US2, US3 | ดูสถานะห้องว่าง/ไม่ว่าง และจองห้อง |
| UC3 | US4 | ดูประวัติและยกเลิกการจอง |
| UC4 | US5 | รับอีเมลยืนยันการจองและแจ้งยกเลิก |

## 3. Feedback Collection

### ข้อมูลการทดสอบ
- วันที่ทดสอบ: 20 ตุลาคม 2569
- จำนวนผู้ทดลองใช้: 10 คน
- กลุ่มผู้ทดลองใช้: นักศึกษาสาขาวิทยาการคอมพิวเตอร์ และ TA วิชาCS261
- วิธีการทดสอบ: ให้ผู้ทดลองใช้เว็บไซต์ Sprint 1 ตาม User Stories US1–US5 และรวบรวมความคิดเห็นผ่านการสังเกตและการสัมภาษณ์หลังทดลองใช้

### ขั้นตอนการรวบรวม Feedback
1. ให้ผู้ใช้ทดลองใช้งานเว็บไซต์ Sprint 1 ตาม User Stories US1–US5
2. สังเกตปัญหาและอุปสรรคที่เกิดขึ้นระหว่างการใช้งาน
3. รวบรวมความคิดเห็นและข้อเสนอแนะจากผู้ทดลองใช้
4. จัดกลุ่มปัญหาเป็นด้านตัวหนังสือ การจัดวาง และข้อมูลที่ขาด
5. จัดลำดับความสำคัญของปัญหาร่วมกับ Product Owner (PO) ก่อนเริ่ม Task 54

## 4. Issues and Improvements

| ประเภทปัญหา | หน้า / US | ปัญหาที่พบ | รายการปรับปรุง | Priority |
|---|---|---|---|---|
| ตัวหนังสือ | หน้า Booking / US2, US3 | ขนาดฟอนต์เมนูด้านบนเล็กเกินไป | เพิ่มขนาดฟอนต์เมนูด้านบน | High |
| ข้อมูลที่ขาด | หน้า Booking / US2 | ไม่มีช่องแสดงเวลาปัจจุบัน | เพิ่มช่องแสดงเวลาปัจจุบัน | High |
| การจัดวาง | หน้า Booking,Booking-his / - | การจัดวางเมนูชิดและดูยากจนเกินไปในระบบ mobile | ปรับขนาดและจัดองค์ประกอบให้พอดี | Medium |
| - | หน้า Booking / US5 | ไม่พบปัญหาในการรับอีเมลยืนยันการจอง | - | - |

## 5. Expected Outcome
- ได้รวบรวมความคิดเห็นและข้อเสนอแนะจากผู้ทดลองใช้งานเว็บไซต์ Sprint 1 พร้อมข้อมูลวันที่ จำนวน และกลุ่มผู้ทดลองใช้
- ได้จัดกลุ่มปัญหาตามประเภทและเชื่อมโยงกับหน้าเว็บและ User Story ที่เกี่ยวข้อง ได้แก่ ตัวหนังสือ การจัดวาง และข้อมูลที่ขาด
- ได้จัดลำดับความสำคัญของปัญหาร่วมกับ Product Owner (PO) โดยแบ่งเป็น High, Medium และ Low
- ได้ข้อสรุปเกี่ยวกับรายการปรับปรุง UI และแนวทางการแก้ไขตามลำดับความสำคัญ
- นำผลการประเมินและรายการปรับปรุงที่ได้ไปใช้เป็นแนวทางในการออกแบบและพัฒนาหน้าเว็บใหม่ใน Task 54
