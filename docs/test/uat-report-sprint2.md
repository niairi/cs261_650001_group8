# UAT Report – Sprint 2

## 1. Objective

เพื่อทดสอบการยอมรับระบบ TU CS Space ใน Sprint 2 โดยให้ผู้ทดลองใช้กลุ่มเดิมจาก Task53 กลับมาทดลองใช้งานเว็บไซต์เวอร์ชันใหม่ (UI v2) และฟีเจอร์ US5 TC3, US6–US11 เพื่อประเมินว่าระบบสามารถทำงานได้ถูกต้องตามความต้องการของผู้ใช้หรือไม่ รวมถึงตรวจสอบว่าปัญหาที่พบจากการทดสอบรอบแรกได้รับการแก้ไขแล้วหรือไม่

## 2. Scope

การทดสอบครอบคลุมการใช้งาน UI v2 และฟีเจอร์ Sprint 2 ดังนี้

| User Story | รายละเอียด |
|---|---|
| UI v2 | ตรวจสอบฟอนต์เมนู การจัดวาง และข้อมูลบนหน้าจอ |
| UI v2 | ตรวจสอบเวลาปัจจุบันและเวลาเปิดบริการ 09:00–16:00 |
| US5 TC3 | ตรวจสอบการจองเมื่อ Email ส่งไม่สำเร็จ |
| US6 | แก้ไข Booking และตรวจสอบเงื่อนไขการแก้ไข |
| US7 | จัดการ Booking สำหรับ Admin |
| US8 | Check-in และตรวจสอบเงื่อนไข Location |
| US9 | ตรวจสอบ No-show และสถานะ Booking |

| US11 TC1 | ทดสอบ Logout |

## 8. Issues and Bug Reports

จาก 28 Test Cases ไม่พบ Test Case ที่ไม่ผ่าน โดย UAT-01 (US5 TC3) ทดสอบด้วยการจำลอง SMTP failure (mock) เนื่องจากไม่ได้ตั้งค่า SMTP จริง และไม่พบ Bug ที่ต้องส่งต่อ

อย่างไรก็ตาม มีข้อเสนอแนะเพิ่มเติมจากผู้ทดลองใช้เกี่ยวกับการจัดวาง Mobile และข้อความแจ้งเตือน ซึ่งสามารถนำไปพิจารณาปรับปรุงในรอบถัดไปได้

## 9. Conclusion

จากการทดสอบ UAT ของระบบ TU CS Space ใน Sprint 2 พบว่า UI v2 มีการปรับปรุงจากข้อเสนอแนะของผู้ทดลองใช้ใน Task53 ได้อย่างเหมาะสม โดยเฉพาะการปรับขนาดฟอนต์เมนู การเพิ่มการแสดงเวลาปัจจุบัน และการจัดวางองค์ประกอบบน Mobile

ในส่วนของฟีเจอร์ US5 TC3 และ US6–US11 ระบบผ่านการทดสอบตามเงื่อนไขที่กำหนด โดย US5 TC3 ทดสอบกรณี SMTP failure ด้วย mock (ไม่ได้ทดสอบกับ SMTP จริง) ส่วนฟีเจอร์อื่นครอบคลุมการแก้ไข Booking การจัดการ Booking สำหรับ Admin การ Check-in การตรวจสอบ No-show การจัดการ Blacklist และการ Logout

โดยสรุป การปรับปรุงใน Sprint 2 ช่วยให้ระบบมีความครบถ้วนและสะดวกต่อการใช้งานมากขึ้นเมื่อเทียบกับ Sprint 1 และสามารถนำข้อเสนอแนะเพิ่มเติมไปใช้พัฒนาระบบใน Sprint ถัดไปได้
