# System Test Cases

## Flow 1: เข้าสู่ระบบ → ดูตารางห้อง → จองห้อง → ได้รับอีเมลยืนยัน

**User Stories:** US1 → US2 → US3 → US5

| Test ID | ขั้นตอน | การดำเนินการ | ผลลัพธ์ที่คาดหวัง |
|---|---:|---|---|
| SYS-01 | 1 | เข้าสู่ระบบด้วยบัญชีผู้ใช้ที่ถูกต้อง | ผู้ใช้สามารถเข้าสู่ระบบและเข้าใช้งานระบบได้สำเร็จ |
| SYS-01 | 2 | ดูตารางการใช้ห้อง | ระบบแสดงข้อมูลห้องและตารางการจอง |
| SYS-01 | 3 | เลือกห้องที่ว่างและทำการจอง | ระบบสร้างรายการจองสำเร็จ |
| SYS-01 | 4 | ตรวจสอบอีเมลยืนยันการจอง | ผู้ใช้ได้รับอีเมลยืนยันการจองสำเร็จ |

**ผลลัพธ์โดยรวมที่คาดหวัง:**  
ผู้ใช้สามารถดำเนินการตั้งแต่เข้าสู่ระบบ ดูตารางห้อง ทำการจองห้อง และได้รับอีเมลยืนยันการจองได้สำเร็จ

## Flow 2: ดูรายการจอง → ยกเลิกการจอง → ได้รับอีเมลแจ้งเตือน

**User Stories:** US4 → US5

| Test ID | ขั้นตอน | การดำเนินการ | ผลลัพธ์ที่คาดหวัง |
|---|---:|---|---|
| SYS-02 | 1 | ดูรายการจองของผู้ใช้ | ระบบแสดงรายการจองที่มีอยู่ของผู้ใช้ |
| SYS-02 | 2 | เลือกรายการจองที่ต้องการยกเลิก | ระบบแสดงข้อมูลของรายการจองที่เลือก |
| SYS-02 | 3 | ยกเลิกรายการจอง | ระบบยกเลิกรายการจองสำเร็จ |
| SYS-02 | 4 | ตรวจสอบอีเมลแจ้งการยกเลิก | ผู้ใช้ได้รับอีเมลแจ้งการยกเลิกการจองสำเร็จ |

**ผลลัพธ์โดยรวมที่คาดหวัง:**  
ผู้ใช้สามารถดูรายการจอง ยกเลิกรายการจอง และได้รับอีเมลแจ้งการยกเลิกได้สำเร็จ
